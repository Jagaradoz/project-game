# โครงรายงานโครงงาน — เว็บไซต์เกมออกกำลังกายผ่านเว็บแคม (ธีมผีไทย)

เอกสารนี้คือโครงเล่มรายงานฉบับสมบูรณ์ ใช้เป็นสารบัญที่ยังไม่มีเนื้อหา แต่ระบุแล้วว่าแต่ละหัวข้อ
ดึงเนื้อหาจากที่ไหนในโปรเจกต์ และต้องเขียนเพิ่มอะไร

- **สถาบัน** โครงงานนี้ทำที่มหาวิทยาลัยเกษตรศาสตร์ (รายวิชา 01418499 โครงงานวิทยาการคอมพิวเตอร์) ส่วนเอกสารต้นแบบทั้งสองฉบับเป็นของจุฬาฯ
  ใช้เป็นแบบโครงสร้างและแหล่งอ้างอิงเท่านั้น ไม่ยกหน้าอนุมัติ ข้อความรับรอง หรือรหัสวิชา 2301499 ของจุฬาฯ มาใช้
  ให้ใช้รูปแบบเล่มที่ภาควิชา/คณะของคุณที่ มก. กำหนด ตอนนี้โฟกัสที่เนื้อหา แล้วค่อยจัดรูปแบบตามแบบ มก. ทีหลัง
- **โครงเล่ม** ยืมจากรายงาน CrossMind (จุฬาฯ 2562, 68 หน้า): บทนำ, ความรู้พื้นฐาน, ออกแบบและพัฒนา, ทดสอบ, สรุป, ภาคผนวก
- **เนื้อหาธีมผีไทยและอ้างอิง** ยืมจากวิทยานิพนธ์ของธิมา ไหมแพง (2562) *เกมสยองขวัญและเกมผีไทยบนแพลตฟอร์มดิจิทัลกับทุนทางวัฒนธรรม*
  ใช้เป็นแหล่งอ้างอิงและคลังแนวคิดออกแบบ ไม่ได้ใช้เป็นต้นแบบวิธีวิจัย (ไม่ต้องทำ textual analysis หรือสัมภาษณ์ผู้ผลิต)
- **วิธีประเมิน** ใช้ของโครงงานนี้เอง: กลุ่มทดลอง/กลุ่มควบคุม + IMI + t-test ตาม [Proposal.md](Proposal.md)
  (CrossMind ใช้ผู้ทดสอบ 13 คนและรายงานแค่ค่าเฉลี่ย ไม่ต้องเอาแบบนั้น)

สัญลักษณ์สถานะ: ✅ มีเนื้อหาให้ย้ายมาแล้ว · 🟡 มีบางส่วน ต้องเสริม · ⬜ ต้องเขียนใหม่ / รอข้อมูลจากการทดลอง

### 4.3 ประเมินผลการเล่น (ตัวเลขจากบันทึกการเล่น)

**ผู้เข้าร่วม** — ตารางข้อมูลพื้นฐานแบบ CrossMind ตาราง 4.1 (คอลัมน์ จำนวน และ ร้อยละ): เพศ, ช่วงอายุ, ชั่วโมงเล่นเกมต่อวัน, เคยเล่น exergame หรือไม่ · แยกตามกลุ่มทดลอง/ควบคุม
จำนวนต่อกลุ่ม: [กำหนดร่วมกับอาจารย์ที่ปรึกษา] (CrossMind ใช้ 13 คนรวม ซึ่งน้อยเกินไปสำหรับเทียบสองกลุ่มด้วย t-test)

**ตัวชี้วัดจากบันทึกการเล่น** — ตัวเลขทั้งหมดต้องออกจากระบบอัตโนมัติ ไม่จดมือ

| ตัวชี้วัด | หน่วย | ใช้กับ | ในโค้ดตอนนี้ |
|---|---|---|---|
| คะแนน (= ศัตรูที่ยิงโดน) | ตัว | เฉพาะกลุ่มทดลอง | มี: `score` ใน [state.js](../src/game/state.js) |
| ระยะทางที่ไปได้ | หน่วยโลกเกม | เฉพาะกลุ่มทดลอง | มี: `distance` |
| เวลาเล่นต่อรอบ | วินาที | ทั้งสองกลุ่ม | มี: `elapsedMs` |
| HP ที่เหลือ / จำนวนครั้งที่โดน | ครั้ง | เฉพาะกลุ่มทดลอง | มี: `hp` (โดนกี่ครั้ง = `maxHp` − `hp`) |
| จำนวนก้าววิ่งอยู่กับที่ | ก้าว | ทั้งสองกลุ่ม | **ยังไม่ได้เก็บ**: `stepCount` ใน [jog.js](../src/detectors/jog.js) มีอยู่ แต่แสดงเฉพาะ debug panel ใน [main.js](../src/main.js) ไม่ได้บันทึกต่อรอบ |
| สัดส่วนเวลาที่วิ่งอยู่กับที่ | ร้อยละของเวลาเล่น | ทั้งสองกลุ่ม | **ยังไม่ได้เก็บ** |
| ช่วงเคลื่อนไหวต่อเนื่องที่นานที่สุด | วินาที | ทั้งสองกลุ่ม | **ยังไม่ได้เก็บ** |
| จำนวนครั้งเปลี่ยนเลน (เอียงตัว) | ครั้ง | ทั้งสองกลุ่ม | **ยังไม่ได้เก็บ** |
| กระสุนที่ยิง และอัตราโดน | นัด, ร้อยละ | เฉพาะกลุ่มทดลอง | **ยังไม่ได้เก็บ** |

ตัวชี้วัดที่ **เปรียบเทียบสองกลุ่มได้** มีแค่ที่ใช้กับทั้งสองกลุ่ม (ก้าว, สัดส่วนเวลาวิ่ง, ช่วงต่อเนื่อง, เวลาเล่น, เปลี่ยนเลน) เพราะกลุ่มควบคุมไม่มีศัตรูและไม่มีคะแนน ·
ที่เหลือใช้รายงานเชิงบรรยายของกลุ่มทดลอง · ต้องเพิ่ม logging ก่อนเก็บข้อมูลจริง

### 4.5 การทดลองเรื่องแรงจูงใจ (IMI)

- ผู้เข้าร่วม: จำนวน, ตารางข้อมูลพื้นฐาน (เพศ, อายุ, ความถี่เล่นเกม ตามแบบ CrossMind ตาราง 4.1), การขอความยินยอม, รหัสผู้เข้าร่วม
- กลุ่มทดลอง (เกมฉบับเต็ม) และกลุ่มควบคุม (การเคลื่อนไหวเดียวกันแต่ไม่มีองค์ประกอบเกม)
- เครื่องมือ: IMI ฉบับแปลไทย, back-translation, pilot, Cronbach's Alpha (Proposal ข้อ 9.2)
- ผล: ตารางคะแนน IMI รายมิติ (Interest/Enjoyment, Perceived Competence, Effort/Importance, Pressure/Tension, Value/Usefulness), จำนวนการเคลื่อนไหว, ระยะเวลาเคลื่อนไหวต่อเนื่อง, Independent t-test
- ตารางผล IMI: มิติ | จำนวนข้อ | Cronbach's Alpha | กลุ่มทดลอง ค่าเฉลี่ย ± SD | กลุ่มควบคุม ค่าเฉลี่ย ± SD | t | df | p | Cohen's d (5 มิติ)

> **[ช่องรูป 4.8]** กราฟเปรียบเทียบคะแนน IMI รายมิติระหว่างสองกลุ่ม · ไฟล์: `docs/images/fig-4-8.png`

- ถ้าเลือก D3 แบบให้ Pressure/Tension เป็นผลที่รายงาน ให้อภิปรายแยกหัวข้อ
- สถานะ: ⬜ รอข้อมูล
