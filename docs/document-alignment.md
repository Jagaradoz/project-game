## Pages and terminology to standardize

The website exposes Home, Calibration, Test Mode, Game Mode, Result Summary, and Profile. Home contains instructions and precautions. Permission is a browser camera request inside each relevant flow. Character and starting-difficulty choice are embedded in Game Mode setup; Test Mode has an inline character choice. Personal high scores are part of Profile.

Remove wording that implies accounts, registration/login, profile editing, online competition, a control-group practice study, a standalone consent page, or biome/stage selection. The source documents do not establish those as product screens. Their old implementation comments and README claims have been removed or corrected.

## Evaluation still required

Software tests and a 1,204-second simulated GPU-resource probe passed, but these do not establish the Proposal's real-webcam thresholds. A researcher must still perform and record actual pose trials, manually counted knee lifts at the three paces, and a 20-minute session on the target desktop/laptop. Count observed freezes in addition to automatic body-loss pauses and record environmental conditions. Do not substitute model confidence, simulated poses, or software-rendered screenshots for that evidence.
