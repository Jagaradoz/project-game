# Guided practice implementation handoff

- Objective: implement the pure practice reducer and focused tests only.
- Allowed reads: this handoff, src/engine/core/trial.ts, src/engine/types.ts (pose types), src/engine/detectors/clap.ts, test/trial.test.ts. No broad scans.
- Allowed writes: src/engine/core/practice.ts and test/practice.test.ts only. Supervisor owns version, runtime, UI and diagnostics. Do not delegate.
- Export PracticeGoal = 5 | 10; PracticeMode = 'guided' | 'free'; PracticePhase = 'idle' | 'ready' | 'active' | 'paused' | 'complete' | 'summary'; PracticeState with mode, pose (PoseId), goal, count, phase, prompt (plain English), results (Record<PoseId, 'pending' | 'completed' | 'skipped'>), pauseReason (string | null). Additional internal fields allowed.
- Export createPracticeState(); practiceCommand(state, command); updatePractice(state, events, readout). Commands discriminated by type: start, pause (optional reason), resume, restart, skip, next, select (pose), mode (mode), goal (goal). Readout extends PoseReadout with clapArmed:boolean. PoseEvent will gain optional knee:UpKnee; knee events must match requested side.
- Default guided/lateral/5/idle. Start begins ready setup. Lane: centre, prompted side, return centre = one; alternate sides. Knees: seed raised knee without counting, then count alternating knee events. Hips: hands down before every newly detected hold. Clap: require clapArmed before each clap; match on same frame as arming if event emitted after detector disarms. No timeouts; unrelated detections do not count. Complete goal requires manual Next. Skip records skipped, advances; last Next/Skip reaches summary. select cancels current exercise and selects pose without remount. mode switches cancel active exercise. goal locked during ready/active/paused. Restart clears selected result/count. Resume resets partial rep and starting position, preserves count. Pause only affects ready/active. Completed/skipped statuses retained for other poses.
- Validation: unit tests for both goals, all four rep/reset rules, wrong knee side, unrelated/simultaneous events, pause/resume, mode/selection, restart/skip/summary. Run npm test -- test/practice.test.ts. Return concise changed files, test results, blockers.
